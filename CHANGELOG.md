# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2024-01-15

### Added
- Initial release of Duck.ai Assistant extension
- Inline code completion powered by Duck.ai
- Code generation command for creating code snippets
- Code debugging command for analyzing selected code
- Support for all programming languages in VS Code
- Debounced API calls to prevent rate limiting
- Context menu integration for debugging

### Features
- Real-time inline completions as you type
- Smart API debouncing (500ms)
- Cancellation token support for responsive editing
- Multi-language support
- Output channel for debugging information
